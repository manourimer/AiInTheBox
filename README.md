# Would you let me out of my box?

A minimal static landing page. Open index.html to preview. No installation or build is needed.

## Replace placeholders

Edit index.html to replace https://example.com/cast and https://example.com/crew with your real application forms. Contact links are set to Manou (mrimer@stanford.edu) and Ellen (ellenk27@stanford.edu). Only the form URLs remain placeholders.

Pre-production is in progress through December. Filming is planned for weeks 2–3 of winter quarter.

The background is generated abstract robotic-eye artwork. The FAQ uses native details/summary elements and works without JavaScript. Created with the built-in image-generation tool; see ARTWORK.md for its prompt. The title uses red Times New Roman on one line. Body copy uses DM Sans from Google Fonts, with Arial fallback.

## GitHub Pages

Upload the contents of this folder to your repository root. Under Settings → Pages, select Deploy from a branch, select your branch and /(root), and save.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

No deployment has been performed. All files use relative paths and work under a GitHub Pages project URL.
